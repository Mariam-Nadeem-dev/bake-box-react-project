# Noor's Bake Box 🍰

A bakery shop website built using React and Vite.

## Project Description

Noor's Bake Box is a bakery website created as part of a Web Technologies lab project.

It showcases different bakery products, customer reviews, order information, and contact details.

## Technologies Used

- React
- Vite
- JavaScript
- HTML
- CSS

## Features

- Shop header and navigation
- Bakery product cards
- Reusable components and badges
- Customer reviews
- Order summary
- Contact information and footer
